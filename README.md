# Severn Planner Homebrew tap

Install Severn Planner for Mac with Homebrew:

```sh
brew install --cask jeremyones21-bot/tap/severn-planner
```

The app updates itself. Homebrew reads the same update feed, so `brew upgrade` also picks up new versions after this tap is bumped.

More about the app: https://www.severnplanner.com/mac
